# STM32F103 两轮自平衡小车 (STM32F103-Balance-Car)

> A two-wheeled self-balancing robot based on STM32F103. 
> Learning project following Bilibili UP主 [铁头山羊].

## 📖 项目简介

本项目是基于 STM32F103 微控制器的两轮自平衡小车学习项目。主要目的是通过实战掌握嵌入式开发的核心技能，包括传感器数据采集、电机控制、PID 闭环算法等。

当前代码和资料主要参考自 B站 UP主 **“铁头山羊”** 的教程，在此表示感谢。

## 🗓️ 学习计划 (两周速通版)

计划在 **两周内** 完成基础版本的学习与实物调试，具体安排如下：

- **第 1 周：底层驱动与硬件基础**
  - [ ] 熟悉 STM32F103 开发环境 (Keil / STM32CubeMX)
  - [ ] 电机驱动 (PWM 输出、TB6612 / DRV8833 等驱动芯片)
  - [ ] 编码器数据读取 (定时器编码器模式)
  - [ ] 姿态传感器数据读取 (MPU6050 / I2C 通信)
- **第 2 周：控制算法与综合调试**
  - [ ] 滤波算法 (互补滤波 / 卡尔曼滤波)
  - [ ] PID 控制算法 (直立环、速度环、转向环)
  - [ ] 串级 PID 参数整定
  - [ ] 实物联调与平衡测试

## 🚀 后续 Roadmap (DIY 与进阶)

完成两周的基础学习后，后续计划进行以下升级和魔改：

- [x] 跑通基础版本，实现基本直立与行走
- [ ] **硬件 DIY**：自己画板子 (PCB) 或使用 3D 打印重新设计小车底盘结构
- [ ] **更换主控/版本**：尝试将主控更换为 STM32F4 / ESP32 (增加无线能力) 进行版本迭代
- [ ] **算法升级**：尝试使用更高级的控制算法 (如 LQR) 或移植 FreeRTOS
- [ ] **扩展功能**：增加手机蓝牙 APP 遥控、OLED 屏幕显示状态等

## 🛠️ 硬件与软件环境

- **MCU**: STM32F103C8T6 (或其他 F103 系列)
- **传感器**: MPU6050
- **电机**: 带有霍尔编码器的直流减速电机
- **开发环境**: Keil MDK / STM32CubeMX
- **辅助工具**: 串口调试助手、PID 调试上位机

## 📝 注意事项

1. 本项目为个人学习记录，代码可能存在不完善之处，欢迎提交 Issue 交流。
2. 调试 PID 时请注意安全，防止电机转速过快导致小车飞车或损坏。
