# STM32F103 两轮自平衡小车 (STM32F103-Balance-Car)

> A two-wheeled self-balancing robot based on STM32F103. 
> Learning project following Bilibili UP主 [铁头山羊].

## 📖 项目简介

本项目是基于 STM32F103 微控制器的两轮自平衡小车学习项目。主要目的是通过实战掌握嵌入式开发的核心技能，包括传感器数据采集、电机控制、PID 闭环算法等。

当前代码和资料主要参考自 B站 UP主 **“铁头山羊”** 的教程，在此表示感谢。

## 🗓️ 学习计划 (十天冲刺版：11.20 - 11.30)

计划在 **十天** 内完成基础版本的学习与实物调试，时间紧凑，具体安排如下：

- **第一阶段：底层驱动与传感器 (11.20 - 11.23)**
  - [ ] **Day 1-2**: 熟悉开发环境，跑通电机 PWM 驱动与编码器数据读取。
  - [ ] **Day 3-4**: 学习 I2C 通信，成功读取 MPU6050 原始数据并进行串口打印。

- **第二阶段：控制算法与直立环 (11.24 - 11.26)**
  - [ ] **Day 5**: 实现姿态解算（互补滤波），获取准确的欧拉角。
  - [ ] **Day 6-7**: 学习 PID 算法理论，编写直立环控制代码，尝试让小车“站起来”。

- **第三阶段：串级 PID 与综合联调 (11.27 - 11.30)**
  - [ ] **Day 8-9**: 引入速度环与转向环，进行串级 PID 的代码编写与初步联调。
  - [ ] **Day 10 (11.30)**: 核心任务：**参数整定**。综合调试小车，实现稳定直立与基础运动，并完成项目总结。

## 🛠️ 硬件与软件环境

- **MCU**: STM32F103C8T6 (或其他 F103 系列)
- **传感器**: MPU6050
- **电机**: 带有霍尔编码器的直流减速电机
- **开发环境**: Keil MDK / STM32CubeMX
- **辅助工具**: 串口调试助手、PID 调试上位机

## 📝 注意事项
